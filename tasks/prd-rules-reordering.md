# PRD: 선박 규율 순서 변경 (Rules Reordering)

## 1. 개요 (Overview)
현재 '선박 규율(Ship's Rules)' 화면에는 규칙 목록이 표시되지만, 드래그 핸들 아이콘(≡)이 시각적으로만 존재하고 실제 기능은 작동하지 않습니다. 사용자가 규칙의 중요도나 선호에 따라 순서를 직접 조정할 수 있도록 드래그 앤 드롭(Drag & Drop) 기능을 구현합니다.

## 2. 목표 (Goals)
*   **드래그 앤 드롭 활성화:** 기존 핸들 아이콘을 사용하여 규칙 항목을 상하로 이동시킬 수 있도록 합니다.
*   **순서 영구 저장:** 이동이 완료되면 변경된 순서를 데이터베이스(Room DB)에 자동으로 반영합니다.
*   **검색 시 기능 제한:** 사용자가 검색어를 입력하여 목록이 필터링된 상태에서는 순서 변경 기능을 비활성화하여 혼선을 방지합니다.

## 3. 사용자 스토리 (User Stories)
*   **선장(사용자)으로서,** 나는 자주 확인하는 규칙을 맨 위로 올리기 위해 드래그 핸들을 잡아 순서를 바꾸고 싶습니다.
*   **선장으로서,** 나는 앱을 껐다 켜더라도 내가 설정한 규칙 순서가 그대로 유지되기를 기대합니다.
*   **선장으로서,** 특정 규칙을 검색하는 중에는 실수로 순서가 바뀌지 않도록 드래그 기능이 잠기기를 원합니다.

## 4. 기능 요구 사항 (Functional Requirements)
1.  **드래그 핸들 인터랙션:** `RuleItem` 내의 `ic_drag_handle` 아이콘을 터치하여 드래그를 시작할 수 있어야 합니다.
2.  **순서 변경 로직:** `LazyColumn` 내에서 항목이 이동할 때 실시간으로 위치가 바뀌는 애니메이션과 시각적 피드백을 제공합니다.
3.  **데이터 저장 (자동 저장):** 드래그를 놓는 순간(Drop), 변경된 리스트의 인덱스를 기반으로 `Rule` 엔티티의 `orderIndex` 값을 업데이트하여 DB에 저장합니다.
4.  **검색 제한:** 검색 바에 텍스트가 입력된 상태에서는 드래그 핸들을 비활성화하거나 기능을 차단합니다.

## 5. 제외 범위 (Non-Goals)
*   **검색 결과 내 순서 변경:** 필터링된 결과 내에서의 순서 편집은 지원하지 않습니다.
*   **수동 저장 버튼:** 별도의 '저장' 버튼 없이 드래그 완료 시 자동으로 저장됩니다.

## 6. 성공 지표 (Success Metrics)
*   **기능 동작:** 규칙 항목을 A 지점에서 B 지점으로 성공적으로 이동시킬 수 있음.
*   **영속성:** 앱 재시작 후에도 변경된 순서가 유지됨.
*   **안정성:** 드래그 및 대량의 순서 변경 작업 시 앱이 비정상 종료되지 않음.

## 7. 미정 사항 및 고려 사항 (Open Questions)
*   **라이브러리 사용:** Jetpack Compose의 기본 기능으로 구현할지, 아니면 `reorderable`과 같은 외부 라이브러리를 사용하여 구현할지는 기술적 편의성에 따라 결정합니다.
