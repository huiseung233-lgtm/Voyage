# PRD: 정박 시 일지 작성 흐름 개선

## 1. Introduction/Overview
현재 게임 내에서 정박을 시도할 때, "일지를 작성하시겠습니까?"라는 질문에 "예"를 선택하면 작성 창이 뜨지 않고 메인 화면으로 이동해버리는 문제가 있습니다. 이 기능을 수정하여, 사용자가 정박 과정에서 게임 화면을 벗어나지 않고 팝업 형태로 일지를 작성할 수 있도록 흐름을 개선합니다.

## 2. Goals
*   **사용자 경험(UX) 개선:** 정박 시 불필요한 화면 전환 없이 게임 화면 내에서 일지 작성을 완료할 수 있게 합니다.
*   **직관적인 흐름:** "작성하겠다"고 선택했을 때 즉시 작성 창을 띄워 사용자의 의도를 바로 반영합니다.
*   **유연한 종료:** 일지 작성 후에도 강제로 메인 화면으로 이동시키지 않고, 사용자가 원할 때 게임을 종료하도록 선택권을 부여합니다.

## 3. User Stories
*   **User Story 1:** 사용자는 항해를 마치고 정박 버튼을 누르면 "오늘의 마지막 일지를 작성하시겠습니까?"라는 확인 팝업을 보게 됩니다.
*   **User Story 2:** 사용자가 확인 팝업에서 **"예, 작성할게요"**를 선택하면, 화면 이동 없이 그 자리에 **일지 작성 팝업(Dialog)**이 뜹니다.
*   **User Story 3:** 사용자가 일지를 다 쓰고 **"저장"**을 누르면, "일지가 저장되었습니다"라는 메시지와 함께 팝업이 닫히고 **게임 화면(GameScreen)이 유지**됩니다. (정박 처리는 완료됨)
*   **User Story 4:** 사용자가 확인 팝업에서 **"아니요"**를 선택하거나, 일지 작성 팝업을 **취소(닫기)**하면, 즉시 정박 처리와 함께 **메인 화면(Home)**으로 이동합니다.

## 4. Functional Requirements
1.  **정박 확인 다이얼로그 (수정)**
    *   "예, 작성할게요" 버튼 클릭 시: `GameActivity`를 종료(`finish`)하지 않고, **게임 화면 위에 일지 작성 다이얼로그**를 표시해야 합니다.
    *   "아니요" 버튼 클릭 시: 기존과 동일하게 정박(`dockShip`) 처리 후 게임 화면을 종료하고 메인 화면으로 이동합니다.

2.  **일지 작성 다이얼로그 (신규/재사용)**
    *   **형태:** 전체 화면이 아닌 **Dialog** 형태 (뒤에 게임 화면이 흐릿하게 보여야 함).
    *   **기능:** `CommonLogbookDialog` 등을 재사용하여 날짜, 내용, 점수 기록 기능을 포함합니다.
    *   **저장(Save) 동작:**
        *   일지 데이터를 저장하고 서버/DB에 반영합니다.
        *   정박(`dockShip`) 처리를 수행합니다.
        *   **중요:** 저장 후 게임 화면을 닫지 않고, 다이얼로그만 닫습니다. (Toast 메시지: "일지 작성 및 정박 완료")
    *   **취소/닫기(Dismiss) 동작:**
        *   작성을 포기한 것으로 간주합니다.
        *   정박(`dockShip`) 처리를 수행합니다.
        *   게임 화면을 종료하고 메인 화면으로 이동합니다.

3.  **ViewModel 로직 수정**
    *   `GameViewModel`에서 일지 작성 요청 시 `navigateToLogbook` 이벤트를 발생시켜 `Activity`를 종료하던 기존 로직을 제거해야 합니다.
    *   대신 `showLogbookDialog`와 같은 상태(State)를 추가하여 Compose UI 내에서 다이얼로그 표시 여부를 제어해야 합니다.

## 5. Non-Goals (Out of Scope)
*   일지 작성 UI의 디자인 전면 개편 (기존 컴포넌트 재사용)
*   정박 외의 다른 상황(예: 메뉴를 통한 일지 진입)에서의 동작 변경

## 6. Success Metrics
*   사용자가 "예"를 눌렀을 때 메인 화면으로 튕겨 나가는 현상이 0건이어야 합니다.
*   일지 작성 후 게임 화면에 남아있을 수 있어야 합니다.
